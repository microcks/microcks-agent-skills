## Installation

### Copilot CLI / Claude Code

```
/plugin marketplace add microcks/microcks-agent-skills
/plugin install plugin2@microcks-agent-skills
```

### VS Code

```json
{
  "chat.plugins.enabled": true,
  "chat.plugins.marketplaces": ["microcks/microcks-agent-skills"]
}
```

Then install the `plugin2` plugin from the plugin browser.
